# Soirée Jeux
Appli de soirée sur un seul téléphone : quiz culture G, blind test (extraits Apple Music), Pictionary et 5 mini-jeux, avec avatars de super-héros, animations et mode soirée qui enchaîne tout.
- Un seul fichier : `index.html` (HTML + CSS + JS, aucune dépendance).
- Publié avec GitHub Pages depuis `main`.
- Les joueurs sont gardés dans le navigateur (localStorage).
